# 07 · 调研结论

> 所有数字均为 2026-10-17 会话内通过 GitHub REST API 实测核验。

## 1. 微信合规（结论性事实）

### 1.1 个人主体小程序：这条路基本关闭

| 项 | 事实 |
|---|---|
| 个人主体开放类目 | 快递邮政 / 教育（**仅"教育信息展示"**）/ 交通 / 生活 / 餐饮 / 旅游 / 工具 / 商业服务 / 体育 |
| 有"游戏"类目吗 | **没有** |
| 教育类目定位 | 官方原文："仅适用于提供教育信息展示服务…不支持教育视频播放/直播、课程产品销售" |
| 违规依据 | 运营规范 5.7.1「个人主体提供的服务，超出个人主体小程序开放的类目范围」→ 可封禁直至下架 |

出处：https://developers.weixin.qq.com/miniprogram/product/material/ 、 https://developers.weixin.qq.com/miniprogram/product/

### 1.2 个人主体小游戏：能注册，但有两道坎

| 项 | 事实 |
|---|---|
| 类目 | 一级类目只有"游戏"，个人主体仅被排除「文化互动 / 角色类 / 牌类」→ 休闲消除可用 |
| 版号 | 个人拿不到（版号只能由持《网络出版服务许可证》的出版单位申报）；不开虚拟支付的路径材料清单里没有版号 |
| 备案 | **免不了**，约 10–30 个工作日；个人可办（身份证 + 人脸核身 + 工信部短信核验） |
| **防沉迷** | 所有微信小游戏已接入腾讯健康系统 → **未成年人仅周五六日及法定节假日 20:00–21:00 玩 1 小时** |

出处：https://developers.weixin.qq.com/minigame/introduction/guide/type.html 、 https://developers.weixin.qq.com/minigame/introduction/guide/zzsh-iaa.html 、 https://www.nppa.gov.cn/xxfb/tzgs/202108/t20210830_666285.html

### 1.3 技术侧
- **纯前端、无服务端、数据仅存本地是允许的**；不使用网络 API 就无需配置服务器域名
- 同声传译 TTS 插件的服务类目是「IT科技 > 软件服务提供商」，**不在个人主体开放范围**（置信度中，需实测）→ 发音不要押在它上面
- 包体上限：小游戏主包 4MB / 总量 30MB；小程序主包 2MB / 总量 30MB

### 1.4 未能核实（不编造）
- 挂教育类目做游戏化练习是否**必被判**类目不符 → 规范无判定条款，属审核裁量
- 非游戏类小程序是否强制接入未成年人模式 → 未在微信官方文档核实
- 无版号小游戏提审是否因"启动页未标注版号"被拒 → 规范内部存在张力，需实提验证
