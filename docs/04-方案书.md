# 04 · 方案书 v1

## 1. 玩法

### 1.1 核心循环
棋盘上随机散落 K 个英文块和 K 个中文释义块（各 K 张，共 2K 张）。
点选两张：配对正确 → 消除、得分、连击 +1；配对错误 → 抖动、连击清零、扣时、记入错词本。
全部消完 → 结算星级 → 解锁下一关。

### 1.2 判定规则（含边界）

| 操作 | 结果 |
|---|---|
| 点第 1 张 | 高亮；若为英文块则播放发音（可关） |
| 再点同一张 | 取消选中 |
| 点第 2 张，配对正确 | 200ms 缩放淡出 → 得分 = 10 × 连击倍率 → 连击 +1 |
| 点第 2 张，配对错误 | 抖动 + 红闪 → 连击清零 → 扣 3 秒 → 该词进错词本 |
| 消除动画中 | 锁定输入（防误触 / 防连点） |
| 全部消完 | 胜利 → 结算 |
| 时间耗尽 | 失败 → 无限重试，**不扣任何东西** |

**取舍**：消除后**留空位不塌陷**。塌陷会让已记忆的位置变化，对低龄儿童造成困惑。

### 1.3 三个年龄段差异

| 维度 | 幼儿园 | 小学 | 初中 |
|---|---|---|---|
| 配对内容 | **Emoji ↔ 英文单词** | 英文词 ↔ 中文释义 | 英文词 ↔ 中文释义（抽象义 / 多义） |
| 是否需要识字 | 否 | 是 | 是 |
| 棋盘规模 | 2×3 ~ 3×4（3–6 对） | 4×4 ~ 5×6（8–15 对） | 5×6 ~ 6×8（15–24 对） |
| 时间压力 | **无计时** | 限时 90–150 秒 | 限时 60–100 秒或步数限制 |
| 错误惩罚 | 仅抖动，不扣分 | 连击清零 + 扣 3 秒 | 扣 5 秒 + 记错词 |
| 语音 | 开局自动朗读本关全部词 | 点英文块朗读（可关） | 可关 |
| 视觉语言 | 糖果色、超大圆角、动物角色、弹性动效 | 明快、进度条、连击数字弹出 | 冷色科技感、数据化、个人最佳 |
| 内容主题 | 动物 / 水果 / 颜色 / 数字 / 身体 | 按教材年级单元同步 | 按中考词频（ECDICT `zk` 标签） |
| 单局时长 | 60–90 秒 | 2–4 分钟 | 3–5 分钟 |

### 1.4 关卡结构与解锁

```
年龄段 → 章节 ×8~12 → 关卡 ×12~15
                        ├─ 普通关（新词）
                        ├─ 复习关（混合前面几关）
                        └─ 章末挑战关（棋盘 +2 对，时间 -20%）
```

- **星级**：3 星 = 零错误且剩余时间 > 50%；2 星 = 错 1–2 次；1 星 = 完成即可
- **解锁**：过前一关解锁下一关；进下一章需当前章累计 ≥ 60% 星数
- **等级 XP**：每关 10 + 星级×5 + 连击奖励；仅用于展示（首版不做皮肤）

### 1.5 难度自适应

采集：正确率 `acc`、平均每对耗时 `t`、星级 `s`

`skill = 0.5×acc + 0.3×speedScore + 0.2×(s/3)`，其中 `speedScore = clamp(基准耗时 ÷ t, 0, 1.5)`

| skill | 档位 | 调整 |
|---|---|---|
| ≥ 0.75 | 挑战 | 词对 +1、时间 −15%、开干扰项 |
| 0.45–0.75 | 合适 | 不变 |
| < 0.45 | 轻松 | 词对 −1、时间 +25%、关干扰项 |

触发：第 10 关后首算，之后每 5 关滚动重算。**单次调整封顶**（±1 对 / ±15% 时间）。

## 2. 页面流程

```
打开链接
 ├─ 本地无档案 → 引导页（≤30 秒）：选年龄段 → 选年级 → 生成匿名 deviceId → 进地图
 └─ 有档案 → 直接进地图

关卡地图（首页）
 ├─ 顶部：年龄段+年级 · 等级 XP
 ├─ 章节横向滑动 → 关卡节点（锁 / 星）
 └─ 底部 Tab：闯关 ｜ 错词本 ｜ 设置

游戏页
 ├─ 顶栏：返回 · 关卡号 · 计时条或步数 · 暂停
 ├─ 主区：自适应棋盘
 ├─ 状态：得分 · 连击
 └─ 结算层：星级动画 · 得分 · 用时 · 本关错词 · [再来一次][下一关][返回]

错词本 → 词 / 释义 / 发音 / 错次 → [只练错词]

设置 → 切换年龄段/年级 · 音效 · 朗读 · 清空数据 · 隐私说明
```

## 3. 技术选型

| 项 | 选择 | 原因 |
|---|---|---|
| 形态 | 纯静态站点 | 零服务器、零成本、零运维 |
| 语言 | 原生 JS (ES2019) + HTML + CSS | 本机无 Node |
| 构建 | **无构建** | 改完文件刷新即见 |
| 渲染 | DOM + CSS 动画 | 调试直观；逻辑层可复用 |
| 模块化 | 多文件 + 传统 `<script>` + 命名空间对象 | 避开 ES Module 在 `file://` 的 CORS 限制 |
| 存储 | 词库 = 静态 JSON；进度 = localStorage | 零后端 |
| 音频 | 优先 `speechSynthesis`；不可用则内置短音效 | 零成本零版权 |
| 托管 | Cloudflare Pages（备选 GitHub Pages） | 国内访问更稳 |
| 后台 | Cloudflare Workers + D1 | 免费额度足 |
| 版本管理 | git + GitHub | 已就绪 |

## 6. 合规要点

### 现状（网页版）
- 不走微信审核；无账号、无付费、无广告、无社交
- 未成年人保护风险：**最低档**
- 必须做：**隐私说明页**（收集什么 / 不收集什么 / 存哪 / 怎么删）

2. 类目「游戏」，二级避开文化互动 / 角色类 / 牌类

4. 备案：身份证 + 人脸核身 + 工信部短信核验
5. 适龄提示：设置并送审，启动页展示
6. 健康系统自动接入 → **未成年人仅周五六日及法定节假日 20:00–21:00 玩 1 小时**
7. 包体：主包 ≤ 4MB，总量 ≤ 30MB

## 7. 代码结构与维护

```
english-match/
 ├─ index.html          # 唯一入口
 ├─ css/ style.css      # 全站样式与动效
 ├─ js/
 │   ├─ core-board.js    # 棋盘生成 / 匹配判定（纯逻辑，禁止出现 document）
 │   ├─ core-score.js    # 计分 / 连击 / 星级
 │   ├─ core-adaptive.js # 难度自适应
 │   ├─ ui-render.js     # 渲染（转小游戏时只重写这一个）
 │   ├─ platform.js      # 存储 / 音频 / 上报（网页与小游戏两套实现）
 │   └─ app.js           # 路由与装配
 ├─ data/ words.*.json  # 词库
 ├─ assets/             # 图片、音效
 ├─ docs/               # 本文档目录
 └─ VERSION.md          # 改动日志，一次一行
```

**三条铁律**
1. `core-*` 里不允许出现 `document` → 转小游戏时逻辑层零改动
2. 加内容只动 `data/`，改外观只动 `css/`，改玩法才动 `js/`
3. 每次改动记一行 `VERSION.md` → 出问题能回滚
