# 03 · 决策记录

> 规则：这里每一条都是**需求方已确认**的。要改必须先问，不能自行推翻。

| 编号 | 决策点 | 结论 | 理由 | 状态 |
|---|---|---|---|---|
| D-01 | 主体资质 | 个人主体，无营业执照，非盈利 | 用户实际情况 | ✅ |
| D-02 | 载体形态 | **纯静态网页版**（不是小程序，不是小游戏） | 个人主体小程序无游戏类目；小游戏有防沉迷时间限制，与儿童教育场景冲突 | ✅ |
| D-03 | 转小游戏 | 预留适配层，后续再试 | 用户希望保留上架可能 | ✅ |
| D-04 | 玩法核心 | 方块配对消除：英文块 ↔ 中文释义块，点选配对成功即消除 | 用户示例"类似消消乐" | ✅ |
| D-05 | 幼儿园配对 | Emoji ↔ 英文单词（非中文释义） | 3–6 岁不识字 | ✅ |
| D-06 | 对抗机制 | ❌ **取消**。改走关卡解锁 + 等级 + 星级 | 用户判断"对抗形式不适合" | ✅ |
| D-07 | 视觉素材 | AI 生成插画 / UI / 特效 | 零预算、无外包 | ✅ |
| D-08 | 信息采集 | 只收「年龄段 + 年级」 | 用户指定 | ✅ |
| D-09 | 难度自适应 | 由前 10 关的得分/速度推算熟练度，动态调整难度 | 用户指定 | ✅ |
| D-10 | 渲染方式 | **DOM + CSS 动画**（不用 Canvas） | 调试直观；逻辑层可复用；Canvas 自己算布局对无基础者过难 | ✅ |
| D-11 | 代码组织 | 多文件 + 传统 `<script>` + 命名空间，**无构建** | 用户机器无 node；ES Module 在 `file://` 下会被 CORS 拦截 | ✅ |
| D-12 | 托管 | **Cloudflare Pages**（GitHub Pages 作备选） | 国内访问通常更稳；与后台同平台 | ✅ |
| D-13 | 后台 | **Cloudflare Workers + D1** | 免费额度足；与托管同一家 | ✅ |
| D-14 | 数据源 | ECDICT（MIT）作主词库；分级自建 | 唯一可整表再分发的词库 | ✅ |
| D-15 | 首发内容 | 小学 1 个年级、约 100 词 | 控制范围，先跑通闭环 | ✅ |
| D-16 | **运行设备** | **手机端**（不是电脑） | 用户明确 | ✅ |
| D-17 | 本地预览 | 因无 Node/Python，用 git push + 云端部署预览；局域网脚本作加速手段 | 用户机器环境实测 | ✅ |
