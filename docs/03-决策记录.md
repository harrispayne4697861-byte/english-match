| D-17 | 本地预览 | 因无 Node/Python，用 git push + 云端部署预览；局域网脚本作加速手段 | 用户机器环境实测 | ✅ |
| D-18 | 视觉风格 | **糖果暖色系**：奶油底 #FFF9F0、主色橙 #F08A3C、点缀薄荷 #8FD9C0 / 天蓝 #9BD3EE / 淡紫 #c9b6f5；扁平 + 大圆角 | 儿童友好；与消消乐类休闲游戏观感一致 | ✅ |
