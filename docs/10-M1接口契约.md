## 0. 全局约定（所有文件都必须遵守）

- 命名空间统一挂 `window.EM`，每个文件一个 IIFE，函数内 `'use strict'`。
- **语言风格沿用现有代码**：`var` + `function`。禁止 import / export / require / `type="module"` / 箭头函数 / class / async。
- 禁止新增任何第三方库、构建步骤、网络请求、npm 依赖。
- 代码与数据中**不得出现 `http://` 或 `https://` 字符串**。
- 每个文件顶部写 3–6 行注释：这个文件干什么、被别人怎么用。
- 所有中文注释用中文标点；字符串里的中文用全角标点。
- 文件加载顺序（由调度者维护 index.html，**执行者不得修改 index.html**）：
  `js/platform.js` → `js/data-words.js` → `js/core-game.js` → `js/ui-game.js` → `js/app.js`

## 1. 共享结构 · Word

```js
{ id: 'p3-001', en: 'apple', zh: '苹果', ph: 'ˈæpl', emoji: '🍎' }
```

| 字段 | 类型 | 约束 |
|---|---|---|
| id | string | 全局唯一，格式 `<段缩写><年级>-<三位序号>`，如 `p3-001` |
| en | string | 全小写，可含空格（如 `ice cream`） |
| zh | string | 单一义项，不超过 6 个汉字，不加"的""了"等语气词 |
| ph | string | 音标，**不含两侧斜杠**，允许空串 `''` |
| emoji | string | 单个 emoji，允许空串 `''`（小学/初中段不用） |

段缩写：`k`=幼儿园、`p`=小学、`j`=初中。

## 2. 共享结构 · Tile

```js
{ tileId: 't0', pairId: 'p0', wordId: 'p3-001', face: 'en', text: 'apple', matched: false }
```

一关 `pairs = K`，就生成 `2K` 个 Tile；同一 `pairId` 恰好两个 Tile，`face` 一个 `en`、一个 `zh`（幼儿园段是 `emoji` + `en`）。

## 4. 文件二 · `js/core-game.js` —— 纯逻辑（执行者 B）

**硬约束：这个文件里不得出现 `document`、`localStorage`、`setTimeout`、`requestAnimationFrame`。**
它必须能在没有 DOM 的环境里跑（自测就是在 node 里跑的）。

```js
window.EM = window.EM || {};
window.EM.Game = {
  getWords: function (stage, grade) { /* -> [Word]，缺失返回 [] */ },
  hasContent: function (stage, grade) { /* -> boolean */ },
  makeRng: function (seed) { /* -> function() -> number in [0,1) */ },
  buildTiles: function (words, rng) { /* -> [Tile]，已打乱 */ },
  createSession: function (opts) { /* -> Session */ }
};
```

`opts = { words: [Word], pairs: 4, seconds: 120, seed: 12345, faceA: 'en', faceB: 'zh' }`
（`words` 至少 `pairs` 条；调用方负责先切好词。`faceA/faceB` 决定两块各显示什么。）

**Session 对外接口**（只读字段 + 方法；内部数组不得被外部直接改写）：

| 成员 | 说明 |
|---|---|
| `session.tiles` | `[Tile]`，长度 2×pairs |
| `session.score` | 当前得分 |
| `session.combo` | 当前连击 |
| `session.mistakes` | 错误次数 |
| `session.status` | `'playing'` / `'won'` / `'timeup'` |
| `session.timeLeftMs` | 剩余毫秒；`seconds=0` 时为 `Infinity` |
| `session.wrongWordIds` | `[string]`，去重，按首次出错顺序 |
| `session.tap(tileId)` | 返回事件对象，见下 |
| `session.tick(deltaMs)` | 扣时间，返回当前 status |
| `session.stars()` | 1 / 2 / 3；未通关返回 0 |
| `session.summary()` | `{ score, comboMax, mistakes, usedMs, stars, wrongWordIds, status }` |

**`tap()` 返回值**（`type` 只有这四种）：

```js
{ type: 'ignored',  tileId: 't3' }
{ type: 'select',   tileId: 't3', pairId: 'p1', wordId: 'p3-001', face: 'en' }
{ type: 'match',    tileId: 't7', pairId: 'p1', wordId: 'p3-001', gained: 20, combo: 2 }
{ type: 'mismatch', tileId: 't9', pairId: 'p2', wordId: 'p3-005',
  alsoPairId: 'p0', alsoWordId: 'p3-002', timePenaltyMs: 3000 }
```

**判定规则（冻结，不得自行改）**

1. `status !== 'playing'` → `ignored`。
2. 点到已匹配的块 → `ignored`（不扣分、不记错）。
3. 当前没有选中的块 → `select`，把该块标记为选中（`selected` 保存它的 tileId）。
4. 第二次点击同一个 tileId → 取消选中，返回 `ignored`。
5. 第二次点击 `pairId` 相同 → `match`：两块 `matched = true`，`combo += 1`，`score += 10 * combo`（即 gained = 10×combo）。全部匹配后 `status = 'won'`。
6. 第二次点击 `pairId` 不同 → `mismatch`：`combo = 0`，`mistakes += 1`，两个 wordId 记入 `wrongWordIds`（去重）；若 `seconds > 0` 则 `timeLeftMs = max(0, timeLeftMs - 3000)`；两个块回到未选中。
7. `tick`：仅当 `status === 'playing'` 且 `seconds > 0` 时递减；减到 0 → `status = 'timeup'`。
8. `stars()`：`status !== 'won'` → 0；`mistakes === 0` 且 `timeLeftMs > 初始时间 × 0.5` → 3；`mistakes <= 2` → 2；否则 1。
9. 随机必须走 `makeRng(seed)`，**同一 seed 两次调用结果逐位相同**。

## 5. 文件三 · `js/ui-game.js` + `css/game.css` —— 渲染（执行者 C）

```js
window.EM.UiGame = {
  start: function (payload) { /* 渲染并开始一关 */ },
  stop:  function () { /* 清掉定时器、解绑事件、清空棋盘 */ }
};
```

`payload = { stage, grade, levelIndex, config, words }`
（`config` 就是 STAGE_CONFIG 里那一段；`words` 是已切好的一关词。）

**它只能操作 index.html 里 `#view-play` 内这三个容器，别的一律不碰：**

```html
<section class="view" id="view-play" hidden>
  <div class="play-top">
    <button class="play-back" id="play-back" type="button">返回</button>
    <span class="play-hud" id="play-hud"></span>
  </div>
  <div class="play-board" id="play-board"></div>
  <div class="play-settle" id="play-settle" hidden></div>
</section>
```

- `#play-hud`：关卡号、分数、连击、剩余时间（不计时段不显示时间）。
- `#play-board`：方块网格。列数 = `config.cols`。**消除后留空位，不塌陷**。
- `#play-settle`：结算面板，含星级、得分、错词数、重玩 / 返回两个按钮。
- `#play-back` 由 UiGame 自己绑点击，**不要用 `data-action`**（那是 app.js 的机制）。

**结束时必须调用** `window.EM.App.onLevelSettle(result)`：

```js
result = { levelIndex: 0, score: 120, stars: 2, mistakes: 1, passed: true,
           wrongWordIds: ['p3-005'], usedMs: 45000 }
```

`passed` = `status === 'won'`。

**UiGame 不得读写 localStorage**，进度持久化全部交给 `EM.App`。
