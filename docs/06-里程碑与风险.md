# 06 · 里程碑与风险

## 里程碑（按每周 6–8 小时碎片时间估算）

| 阶段 | 内容 | 工时 | 验收标准 |
|---|---|---|---|
| **M0 脚手架** | 目录结构、首页、localStorage、移动端 viewport、三 Tab 空壳 | 6h | **手机**打开能看到页面，竖屏无溢出，三个 Tab 可切换 |
| **M1 可玩原型** | 棋盘生成、点选判定、计分、单关卡（无美术） | 12h | 能完整玩完一关，正确/错误都有明确反馈 |
| **M2 关卡与进度** | 关卡地图、解锁、星级、结算层 | 9h | 过关后解锁下一关，刷新后进度仍在 |
| **M3 内容接入** | ECDICT → 精简词库脚本、100 词试跑、错词本 | 12h | 真实词库能玩，错词进错词本，[只练错词]可用 |
| **M4 三龄段与视觉** | 三套主题、AI 素材、音效/朗读、难度自适应 | 12h | 三档各自能玩且风格明显不同，难度会随表现变化 |
| **M5 后台与发布** | 事件上报、看板、正式部署 | 9h | 发给朋友能打开，后台能看到数据与反馈 |

**合计约 10 周 / 60 小时。**

## 风险清单

| 风险 | 概率 | 影响 | 应对 |
|---|---|---|---|
| 词库分级不专业（AI 做不到教研级判断） | 高 | 中 | 先用牛津三千/词频粗分级，**标注"参考分级"**，后续请英语老师校核 |
| `speechSynthesis` 在微信内置浏览器不可用 | 中 | 中 | 朗读不做必需路径；M4 实测后再决定是否内置音频 |
| 国内访问 Cloudflare Pages / GitHub Pages 不稳 | 中 | 中 | 两家都试，用实测结果定 |
| 无代码基础，改坏了修不回来 | 高 | 高 | 分层架构 + `VERSION.md` + git 提交 |
| 内容量失控，永远做不完 | 高 | 高 | **首版只做 1 个年级 100 词**，其余按批补 |
| 手机端适配在电脑上看不出来 | 高 | 中 | 每次改动必须真机验证，见 `05-移动端设计要求.md` 第 6 节 |
| 将来上小游戏被防沉迷挡住（未成年仅周五六日 20–21 点） | 高 | 高 | 上架前重新评估，见 `07-调研结论.md` |
| 首次 git push 凭据不可用 | 中 | 低 | 改用 GitHub Desktop，或生成 Personal Access Token |
