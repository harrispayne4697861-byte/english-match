### 已踩的坑（务必保留修复方式）

**坑 1：.bat 文件里不能写中文 + 不能是 UTF-8**
- 现象：双击后 cmd 报一堆 `'xx' 不是内部或外部命令`，内容乱码。
- 原因：cmd 按系统代码页（GBK）解析文件，UTF-8 中文被拆成乱码字节，破坏了 if/for 块的语法。
- 修复：**bat 内只用 ASCII 字符**，中文一律交给 `node` 打印。

**坑 2：.bat 必须是 CRLF 换行**
- 现象：即使全是 ASCII，逻辑也错乱（块结构被误读）。
- 原因：`write` 工具默认写 LF；cmd 要求 CRLF。
- 修复：写完用 PowerShell 强制转换
  ```powershell
  Get-ChildItem -Filter *.bat | ForEach-Object {
    $t = [System.IO.File]::ReadAllText($_.FullName)
    [System.IO.File]::WriteAllText($_.FullName, ($t -replace "\r?\n", "`r`n"), [System.Text.UTF8Encoding]::new($false))
  }
  ```

**坑 3：用 PowerShell 命令里带中文绝对路径会偶发解析失败**
- 现象：`ParserError`，路径显示成 `������`。
- 规避：用 `workdir` 参数 + 相对路径，或用通配符 `Get-ChildItem` 取文件对象，命令里不写中文。

**坑 4：防火墙**
- 现象：电脑上能开，手机打不开。
- 修复：防火墙提示选「专用网络」允许；或管理员身份运行 bat。
