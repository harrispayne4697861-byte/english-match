# 13 · 藤蔓关卡地图改造（M2 增补）

> 日期：2026-10-18
> 触发：你手机验收后提出「关卡要像参考图那样挂在藤蔓上、随解锁不断升高、背景从地面升到云端」
> 同时修掉你第 6 条反馈的缺陷：**通关后连线没变实线**。

---

## 1. 先说那个缺陷

- 现象：第 1 关通关后，经验条变长、金星出现，但 1→2 的连线还是虚线。
- 根因：`js/app.js` 里判断「这一段线是否已走过」时，取的是**当前节点**（第 2 关）的星级。第 2 关还没玩，星级是 0，所以永远画成虚线。
- 修复：改成取**前一个节点**（第 1 关）的星级；第 1 关有星，1→2 就是实线。
- 防回归：整机冒烟新增断言「第 1 关到第 2 关的连线变成实线」。断言写完后先反向验证过（旧逻辑会 FAIL）。

---

## 2. 地图形态：可滚动长藤蔓

| 项 | 现在的做法 |
|---|---|
| 排布 | 关卡从下往上排，左右交替挂在藤蔓两侧（`swing = ±13.5%`），纵向间距 126px |
| 藤蔓 | SVG 路径穿过每个节点中心，S 形贝塞尔 + 小叶点缀；主藤 26px 深绿 + 10px 亮绿高光 |
| 连线状态 | 已走过的段＝亮绿实线；没走过的段＝白色虚线（原树状图的两段式保留） |
| 滚动 | 整页纵向滚动；**进地图自动滚到当前关**（当前关停在屏幕 66% 高度，越往上越"高"） |
| 节点 | 花苞（未解锁，浅绿椭圆 + 锁）→ 青果（已解锁未通关）→ 金果（已通关，带金星）→ 当前关橙色脉冲环 |
| 编号 | 全部保留，白字加深色投影 |
| 契约 | `id="map-grid"`、`data-action="open-level"`、`data-level="N"`、`.tree-node`、`.tree-line` 都没变，测试选择器不用改 |

**节点尺寸 72px、行距 126px**，12 关总高 = 132 + 11×126 + 200 = **1718px**，比一屏长，所以有"往上爬"的滚动感。

## 3. 背景四层，跟"解锁进度"走

你原话是「随着关卡的解锁，树藤不断升高，背景图从地面上升到空中，到云端之上」，所以背景**由解锁进度驱动，不是由滚动位置驱动**。

映射公式（`js/app.js` renderMap 末尾）：

```
f = 当前关序号 / (总关数 - 1) * 3      // 0=地面 1=林间 2=云层 3=云端之上
```

12 关时：第 1 关 f=0（地面）、第 5 关 f≈1.09（林间）、第 9 关 f≈2.18（云层）、第 12 关 f=3（云端之上），相邻两层按 1-|f-k| 交叉淡入，CSS `transition: opacity .24s`。

四层内容（全部纯 CSS 渐变，**零图片、零下载**）：

| 层 | 观感 |
|---|---|
| 0 地面 | 淡蓝天空 + 底部绿色山丘 |
| 1 林间 | 顶部树冠投影 + 两侧树影 + 更深草地 |
| 2 云层 | 蓝天 + 三团白云 |
| 3 云端之上 | 深紫夜空 + 月亮光晕 + 星点 + 底部云海 |

顶部有一层奶油色蒙版（`map-sky::after`），保证标题与经验条在夜空那层也读得清；经验条改成 `position: sticky`，滚动时一直贴顶。
