## 三句话讲完这个项目

1. **玩法**：棋盘上混着英文块和中文释义块，点出"英文 + 它的中文意思"就消除，消完过关，攒星解锁。
2. **三重约束**：零预算、单人、无代码基础 → 所以是**纯静态网页 + 无构建 + 本地存储**，没有任何需要安装的工具。
3. **运行设备是手机**，不是电脑 —— 所有布局、触控、性能都必须按手机端设计。
